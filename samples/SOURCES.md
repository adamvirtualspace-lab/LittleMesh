# Sample corpus

Test meshes for LittleMesh, downloaded on demand into `samples/corpus/` (not committed):

```bash
node scripts/fetch-samples.mjs
```

All assets come from [Poly Haven](https://polyhaven.com) and are licensed [CC0](https://polyhaven.com/license) (public domain). The glTF variant with 1k textures is used.
